# Lab Test Report Analyzer with Medical Assistant

A comprehensive web application that helps users analyze their laboratory test reports and provides AI-powered medical guidance.

## 🏥 Features

✅ Test Report Upload & Analysis
✅ AI-Powered Medical Assistant
✅ Comprehensive Test Database
✅ User Dashboard & History
✅ Privacy & Security

## Tech Stack

- **Frontend**: React 18 + Material-UI
- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **AI**: OpenAI GPT-4
- **DevOps**: Docker & Docker Compose

## Quick Start

```bash
git clone https://github.com/Iswaryasureshbabu/lab-test-analyzer.git
cd lab-test-analyzer
cp .env.example .env
docker-compose up -d
```

Access at http://localhost:3000

## 📍 Access Points
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:5000
- **API Documentation**: http://localhost:5000/api
